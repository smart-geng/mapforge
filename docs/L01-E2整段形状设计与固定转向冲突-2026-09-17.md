## 1. 结论：主路单独修形不能满足本次完整来源条件

v0.6范围允许编辑road11约150m五条边界，但固定106–111六条关联转向。完整原件账本把普通道路末端约6m边界分配给这些转向，因此固定转向也必须满足对应原边界的既有**最大0.35m**尾段预算，不能套连接路via的宽松P95或L01的0.75m研究包络。

检查实际XODR参考原语、laneOffset和width后，四条固定转向上找到五处超限点：

| 固定转向 / 物理侧 | 转向自身s（m） | 到完整同身份原边界的距离（m） |
|---|---:|---:|
| 106 / left | 5.75 | 0.399805 |
| 107 / left | 1.75 | 0.357149 |
| 107 / right | 5.75 | 0.394064 |
| 110 / right | 5.00 | 0.386714 |
| 111 / right | 6.00 | 0.554103 |

这里的left/right是连接路沿正向s行驶时的左右边缘，原IBD关系经既有来源/端口关系绑定，未直接把图商SIDE名称当成行驶左右。

**必要条件推理**：这些点由固定转向文件中的原语和横断面决定，与可变road11内部边界系数无关。只要该转向仍固定，改变主路形状、求解器、权重或主路结点都不能消除这个点的来源超限。该结论仅针对“当前文件＋这六路固定＋既有尾段门槛”的契约，不是原地图一般无解，也不是必须移动口部的证明。

因此停止在该冻结范围内登记新求解；不把来源账本接通或主路局部修好称为全闭环。

## 2. 为什么这不是渲染或采样误差

证据目录：`out/node4-event-shape-admission-e2-20260917/`。

- 每个见证点直接在文件参考原语的站位求值，再加实际laneOffset/width法向偏移，**没有在渲染网格或折线之间插值**。
- 用原始要素完整part的每一条有限线段求最短距离，不只保留约6m尾段，不去邻车道寻找更近的线；五个失败点的垂足均在线段内部，且位于原尾段域，排除了裁切端点造成的假失败。
- 每0.25m仅用于有限见证位置选择，未生成输出几何。这足以发现失败，不能将未发现超限的108/109称为整段通过；也不声称0.554103m是连续最大值。
- 111在s=6的世界点额外用参考曲率的正余弦积分和独立多项式求值复算，与原求值器在测试中相差小于1e-10m；距离另与Shapely原线段距离核对。

- 0.35m来源见`mapforge/ops/joint_connector_fit.py`的`original_tail_final_max_m`及普通尾段约束；本轮未新增或放宽门槛。

## 3. 整段长曲线表示提案

本提案不增加任何实际结点，也不编译新文件。先确定以下一个共同模型，避免分别拟合后补接缝：

1. **主路**：沿现有Line参考轴定义五条共享物理边界`B0…B4(s)`；laneOffset为B0，车道i宽度为`B(i-1)-Bi`。同一分界只存一份，全部宽度由差值派生。长区间三次边界可直接写出，不经密集采样转换为短线。
2. **两处出生事件**：沿用s131.0543、s151.6089及九处既有角色；新宽度从零产生，接触处位置/一阶/二阶约束共同表达。不得将出生前的独立movement路径改成边界中点。
3. **完整来源**：25边界/19路径清单不变，35个实际区间、4个有限端点观测及六路原尾段消费者一起进入约束。端点观测不是纵向覆盖；通行路径独立验收。
4. **形状意图**：完整上游近直、两次扩宽/横移、趋稳和下游接续分别登记原件走廊、附加极值/反向量和误差。稀疏原弦方向是支持证据，不冒充测绘切向；旧s178病例和原空间域上的研究护栏保留，不能用扩大后的全域总分稀释。
5. **长区间/写出**：只按少数已登记的道路形态事件分配自由度，不按点数设结点。独立区间继续受既有≥6m研究护栏约束；实际XML的语义laneSection换原点记录、独立多项式自由度和最短写出跨度分别统计，不把同一多项式的语义重表达伪装成加了更多曲线能力，也不自动豁免新短记录。
6. **事务**：同一模型贯穿预览、实际XML回读及撤销；零操作仍原字节。图形界面只是输入意图，不能前端画顺后绕过后端来源、形状、面域与消费端检查。

三次width/offset是当前输出表示约束；ASAM说明width沿s为三次多项式，laneSection内有效至下一个width或段末。这支持共享边界差写出路线，不能据此声称数学C2即符合全部世界道路验收。[ASAM车道几何](https://publications.pages.asam.net/standards/ASAM_OpenDRIVE/ASAM_OpenDRIVE_Specification/v1.8.1/specification/11_lanes/11_06_lane_geometry.html)。平滑性仍应检查实际车道边缘及接触关系，而非只看参考轴；此处参考1.8.1解释，输出目标不从1.5M暗中升级。[ASAM平滑性附录](https://publications.pages.asam.net/standards/ASAM_OpenDRIVE/ASAM_OpenDRIVE_Specification/v1.8.1/specification/16_annexes/smoothness_of_lanes/top_ter_smoothness_of_lanes.html)。以上官方条目本轮已在线核对，未增加第三方代码或依赖。
