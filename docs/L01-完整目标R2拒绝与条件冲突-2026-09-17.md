## 4. 为什么不再追加迭代：固定条件下的可核冲突

额外只读脚本`diagnose_refinement_conflict.py`从**同一个保存状态**提取必要条件，未运行优化器、未生成其他目标状态。结果在`necessary-condition-audit/conditions.json`，114项绑定复核无漂移。

位置消元后的局部系数为`u = p + n·z`，z是剩余基系数，不是道路横向米数。原来源/宽度线性护栏首先要求：

`−1.785280113883 ≤ z ≤ 1.490469996331`。

反向量是沿固定原件方向的反向位移积分（平坦来源使用总变差），对系数为凸函数。在保存状态的导数符号区间上求固定有符号位移和，得到对**全部z**有效的仿射下界：

`R(z) ≥ 0.579817761499 + 0.441030671032·z`。

这个下界在保存状态上与原反向量的数值差约5e−16m。结合既有反向量上限及原1e−7m数值余量，必需：

`z ≤ −0.129794593805`。

同时，在已保存的曲率见证站s163.6089，世界边界的切向导数和二阶导数为：

`v(z) = 0.186352507401 + 0.021547859898·z`

`a(z) = −0.059813495100 + 0.007182619966·z`

`|κ(z)| = |a(z)| / (1 + v(z)²)^(3/2)`。

在上述必要区间内，用端点、零点及导数多项式根列全候选极值，最小绝对曲率为**0.057800127835**，仍高于原曲率护栏加数值余量后的**0.056059961594**，间隔约**0.001740166241 1/m**。

因此，即使不考虑其他形状约束，**本次精确目标＋冻结范围/表示＋这两项既有研究护栏已发生条件冲突**，不是增加迭代次数就能解决。该复核采用float64代数求根，不是区间算术或形式认证；结论严格限于本次固定契约，不能外推为原SHP地图一般无解、所有长曲线表示无解或OpenDRIVE不支持。
