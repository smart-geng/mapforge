## 2. Linux 云端从 Git 开始

以下为 x86_64 Linux、有外网的安装命令。uv 0.12.21 已实际下载到锁定 Python 3.11.16，使用旧 uv 找不到解释器时先更新工具；不需要改用 3.11.17，更不能使用 3.12 运行几何证据。

```bash
git -c core.autocrlf=false clone --branch main https://github.com/smart-geng/mapforge.git
cd mapforge
mkdir -p out/cloud-tools
curl -fL https://github.com/astral-sh/uv/releases/download/0.12.21/uv-x86_64-unknown-linux-gnu.tar.gz -o out/cloud-tools/uv.tar.gz
tar xzf out/cloud-tools/uv.tar.gz -C out/cloud-tools
out/cloud-tools/uv-x86_64-unknown-linux-gnu/uv python install 3.11.16 --install-dir out/cloud-tools/python --no-bin
out/cloud-tools/uv-x86_64-unknown-linux-gnu/uv sync --locked --python out/cloud-tools/python/cpython-3.11.16-linux-x86_64-gnu/bin/python3.11
.venv/bin/python scripts/restore_handoff_assets.py --manifest handoff_assets/20261009-base/manifest.json --target .
.venv/bin/python scripts/restore_handoff_assets.py --manifest handoff_assets/20261009-transfer-proof/manifest.json --target .
```

已在本机 Linux 新目录按同一工具版本安装 Python 3.11.16，按 uv.lock 安装全部 56 个锁定包，并恢复原料、证据。不是干净断网机器验收。云端如已有目录，恢复工具会核对已有文件；内容不同或不完整就拒绝，不会用新资料覆盖旧工程。改用全新目录，或人工决定资料取舍。

代理按云端机器实际地址设置，不能照抄本机内网地址。本机验证用 10086 SOCKS / 10087 HTTP 代理，未取消证书检查。安装需要访问 GitHub 和 PyPI。

