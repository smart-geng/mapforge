## 3. 局部投影检查：只证明软件计算

审核采用明确的 lon/lat 度输入，先转弧度，再在声明椭球上作 AEQD 局部投影，输出 east/north 米；没有 datum 纠偏、网格下载或自动轴交换。原点固定在全源边界框中心 `(106.32620559392478, 29.56326540201593)`，不依赖访问顺序。

对原车道 224,024 个分段的 **448,048 个端点样本**（包含相邻段重复端点）正反算，最大平面经纬度数值误差为 **3.1776437161565096e-14°**。原点映射为 `(0,0)`；沿声明椭球向东/向北 100 m 的测试分别得到约 `(100,0)` / `(0,100)`。软件数值容差 `1e-9°` 只用于找计算错误，**不是测绘精度门槛**。

API 轴顺序和投影定义依据 [pyproj Transformer 官方文档](https://pyproj4.github.io/pyproj/stable/api/transformer.html) 与 [PROJ AEQD 官方文档](https://proj.org/en/stable/operations/projections/aeqd.html)。报告记录实际锁定环境的库版本；在线文档较新不构成升级依赖的理由。

可逆投影即使面对整片错误偏移的源坐标也会通过。因此本项 PASS 不能改变 `absolute_crs_verified=false`，也不能替代生产 CRS 门禁。
