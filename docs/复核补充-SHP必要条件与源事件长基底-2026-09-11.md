## 2. 必要条件的推导与限度

对同一单调坐标图中的物理车道中点 `y(x)`，记 `p=y′, r=y″, u=y‴`。当前工况要求 `|κ|≤K=2.5/v²`、`|dκ/dℓ|≤J=1/v³`，其中 `v` 为原速度，ℓ为物理弧长。没有用小角度近似：

```text
q = sin(θ) = p / sqrt(1+p²),  dq/dx = κ
κ = r / (1+p²)^(3/2)
dκ/dℓ = u/(1+p²)² − 3pr²/(1+p²)³
```

原边界完整折线的±0.35m包络给出其中点位置包络。由两观测站位割线和中值定理，至少一个位置的斜率有界；用 `|dq/dx|≤K` 将其扩展到整个待检区间，取得 `|p|≤M`。因此有**必要上界**：

```text
|r| ≤ K(1+M²)^(3/2)
|u| ≤ (J + 3MK²)(1+M²)² = B
```

以Taylor余项约束相邻检查站的值及导数，例如：

```text
|y(x+h) − y(x) − hp(x) − h²r(x)/2| ≤ Bh³/6
|p(x+h) − p(x) − hr(x)| ≤ Bh²/2
|r(x+h) − r(x)| ≤ Bh
```

正反向均加入；不同车道仍共享原边界变量，物理接触保持C2。2m只是检查站距，**不会生成每2m一条曲线**。若无法从来源和曲率推出有限斜率界，该区间标UNAVAILABLE，不以假定小航向角制造冲突。

这不是充分条件：自由检查站的值/导数未必能构成连续边界曲线，两个边界的独立变化也未全面受约束。必要模型通过不能输出地图，更不能证明真实道路已可行。数值冲突仅针对当前固定源接触、同坐标图来源包络与车道中点/工况合同；不是全地图、所有观测解释或自由接触位置的无解证明。14个原中心端部支持不足及两条通行观测路径仍待完整验收，未因必要检查而消失。

## 4. 文献应用，未引入外部实现

- Armin Straub，Numerical Analysis（2022），讲义第27页定理48/49给出Taylor误差项及中值定理。本轮必要条件推导基于这些基本结果与上述精确曲率恒等式，不是从论文中取得“此地图不可行”的结论。[作者讲义](https://arminstraub.com/downloads/teaching/numericalanalysis-fall22/lectures-all.pdf)
- Kielas-Jensen、Cichella，*Bernstein polynomial-based transcription method for solving optimal trajectory generation problems*（2020）。参考其区分连续约束与有限维多项式表示的思路；本轮仍使用自有源身份/边界接触模型，必要条件通过不是其可行轨迹构造。[作者预印本](https://arxiv.org/abs/2010.09992)
- Berscheid、Kröger，*Jerk-limited Real-time Trajectory Generation with Arbitrary Target States*（2021）。这是固定状态间的jerk受限运动生成，不直接解决本项目多边界/身份/整体道路保真；不能套一个时间缩放就偷偷降低来源限速。本轮未接入该库。[作者预印本](https://arxiv.org/abs/2105.04830)

以上均已在线核对；未复制论文配套实现，未新增许可证依赖。
