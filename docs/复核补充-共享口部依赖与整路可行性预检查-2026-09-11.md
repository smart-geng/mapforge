- `spikes/road_constraint_model.py`：整路源约束、正宽约束、端约束、动力学计算行拆成可复用变量块；可以在模型中释放junction端状态，不能单独写出自由端普通路。尚未实现普通路与所有连接的联合非线性求解。
- `scripts/shared_port_preflight.py`：从真实SHP复跑，输出来源、依赖、失败约束和图像；**没有XODR写出路径**。诊断性C0/C1对照不返回可写出的放宽参数。

默认转换器、原件、速度、相位、ID和正式14份输出均未改动。MAP本轮未重转。Web前端尚未开发。

## 3. 真实结果：两个不同层次的冲突

### 3.1 固定30米窗口本身锁住了旧误差

road10长度91.13755506m，窗口起点s=61.13755506m。第−3车道来源`2023081117193442066`的外边界在该切口，旧目标与来源相差 **1.1034426204m**。

如果固定这一切口，仅在末端30m内移动共用边界，不可能同时满足绝对0.35m来源约束。线性预检查最小额外松弛量为0.7534426204m。**报告这一数值不是许可放宽容差**，也不表示改104本身能解决它。

### 3.2 释放所有口部后，当前整路曲线族仍不够

测试固定现有单直线参考轴、独立跨度≥15m的三次B样条物理边界族，保留原始来源约束/非负宽，释放道路junction端状态：76变量，70个自由变量。其线性模型不可行，规范化phase松弛量1.6766478067；该量**不是米**，不可直接当全图误差。

右侧分流发生在写出站位41.3849m。原始分流边界端点投影约s=41.254m、57.378m，约16.12m长度；物理外边界继续向前，新分界线从它分出。左侧同时存在写出站位60m的并流结束事件，原始零宽尖端约s=59.384m。

对照只改变分叉处导数相等条件，来源、基函数、宽度和口部释放方式不变：

| 诊断模型 | 线性可行性 | 说明 |
|---|---|---|
| 所有分合流只绑位置（C0） | 可行 | 仅反事实诊断，不能接受 |
| 所有分合流绑位置/切向（C1） | 可行 | 未满足项目曲率连续要求，不能接受 |
| 所有分合流绑位置/切向/曲率（C2） | 不可行 | 当前严格模型 |
| 仅右侧降为C1，左侧仍C2 | 不可行；phase=0.5994369814 | 对偶支持转移至左侧并流来源 |
| 仅左侧降为C1，右侧仍C2 | 不可行；phase=1.6766478067 | 右侧分流冲突仍在 |

因此不是只改右侧一个事件就能完成，也不是正宽检查误报。当前可确认的是：**所选固定坐标轴、三次长跨度基函数和分合流C2绑定的组合，未能在严格来源范围内表示两处形状**。尚未证明所有少原语模型都不可能，也没有证明原件错误；不把这些诊断参数用于导出。

图中旧XODR的多条虚线有明显偏离/鼓包，用户反馈成立。原始分流支路的LANE_LINK采样又不总是左右边界的几何中线：尖端附近路径与继续车道共线，但其边界宽为零。不能同时不加区分地把它当“通行路径”及“零宽车道中线真值”。该语义问题此前已记录，本轮重新从原件画出，未自动改源/改Profile含义。

## 4. 标准边界：不把自定门槛说成规范条款

已核对ASAM OpenDRIVE 1.8.1：

- [附录D](https://publications.pages.asam.net/standards/ASAM_OpenDRIVE/ASAM_OpenDRIVE_Specification/v1.8.1/specification/16_annexes/smoothness_of_lanes/top_ter_smoothness_of_lanes.html)要求可驾驶车道接触点无间隙、无方向折角，并覆盖width/laneOffset和laneSection等。它并未在该条款规定本项目使用的0.35m、15m、jerk=1或数学C2阈值；后者是工程模型/验收选择。
- [11.5 Lane linkage](https://publications.pages.asam.net/standards/ASAM_OpenDRIVE/ASAM_OpenDRIVE_Specification/v1.8.1/specification/11_lanes/11_05_lane_link.html)区分非零宽的直接连接与旁侧新生车道，零宽起点不应写predecessor。不能为了中心曲线连通把零宽新车道强接为上一车道后继。

仍遵守项目较严格的平滑要求，不因规范只列无折角就降级通过。当前目标写出1.5M未改变；未添加1.8专有元素。
