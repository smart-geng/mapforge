# 来源口部联动与少段连接复核（v1.44）

日期：2026-09-10。结论：**有局部进展，整图仍不可交付**。本轮只处理SHP node4；MAP未重转，既有未完成项不变。未修改原始SHP/XML，未覆盖正式输出，未commit。

## 1. 本轮解决什么

之前固定普通路的旧断面端状态，再让连接路吸收形状差异，部分转弯会产生过冲、负宽和自交。仅把结构口部向外移动6m仍不够：若强制保留两个6m首尾过渡段，新增空间又被占掉。

本轮先用原始中心/边界检查普通路的口部支持域，只在有来源约束的长窗口重建断面，再同时重建依赖它的24条连接。结构路口边界可调整，但**不移动原始停止线、不改源点、不编造TOPO**。这是分阶段联动求解，尚不是全网一次性联合优化。

- 普通路保留长参考轴；口部窗口采用绝对边界误差≤0.35m，所有源顶点进入构造，固定外侧接入端，口部位置在源约束内调整。平行端状态是一种受约束构造，不是把真实道路一律拉直。
- 只有横向一阶导数满足条件时才省去相应首尾过渡段：连接参考原语为3、4或5个，最短6m。中心和左右边缘共同匹配实际文件的端位置/方向/曲率。
- 保留完整实测via及由唯一原始TOPO确定的相邻支持段。复合支持域和原始via分别检查，不能用大量近乎零误差的直行点稀释转弯误差。
- 横断面采用固定5、6或7条三次记录，最短仍可能3m；这不是逐采样点拟合，但也**不能称所有几何记录都很长，或已经满足用户全部少段要求**。世界坐标接头检查是G2，不声称全曲线G3。

## 3. 本轮修掉的实现问题

1. 原始via误差被相邻直线支持稀释：构造侧补独立via约束，与复核器口径对齐。
2. 临界可行解数值端点有微小残差：只求曲线参数闭合，重新检查全部约束；不平移曲线、不扩大最终端闭合门槛。
3. 0.5m构造在阈值上，2cm复算略超限：构造增加1mm来源余量及0.98动力学目标，最终验收门槛不变。不是降速。
4. 候选池曾因旧种子误差略小，丢弃有余量的新解：优先选择满足构造余量的可行候选。112修前2cm jerk1.000009、修后0.980011。
5. 全部变量已固定时LP传入空向量报错：改为直接检查固定约束，真实不相容仍拒绝。
6. 试验XODR根元素顺序错误：新增`spikes/trial_xml.py`，原位替换、保留全部内容、写后XSD验证。
7. 截图调用重复传density/ground_plane，依赖消费者参数优先级：改为只传一次，默认无车辆/无地面。来源标签不再错误声称固定七区间或G3。
