# 联合初始化与 MAP 宽度语义证据

> 2026-09-11，方案 v1.58。**目标未完成，无新合格 XODR；本轮完成的是联合初始化实现、真实失败定位与原件语义复核。** 原件、旧地图、来源限速、ID/phase 未改；没有 commit。

## 1. 为什么不是继续逐条磨曲线

v1.57 已能把普通道路边界、参考轴方向及全部连接放进同一状态，但入口仍要求每条普通道路先在固定轴下可行。这会在联合求解之前拒绝可能需要整体调整的输入。另一方面，新增常宽门禁避免了自由边界任意压窄，却把一个未经来源充分证明的假设引入求解：MAP 的单个 laneWidth 被解释成整个原点支持范围内的固定 t 向宽度。

这两个问题须分开解决：**工程入口修复不需要修改来源；改变标量宽度的解释则属于转换合同决策，不能为了求解通过偷偷更改。** 原点、点间几何假设、物理边界、标量属性也不能再混成一种真值。

## 2. 已实施：不依赖单路先通过的联合入口

`spikes/joint_corridor_connectors.py` / `scripts/rebuild_map_joint.py` 增加 `--joint-initialization`，仅与 `--coupled --restore-joint --rotating-axes` 一起使用，默认几何未推广。

1. 全部普通路仅投影为相同长三次基底的**未合格初值**，状态为 `JOINT_SEED_ONLY`，不再要求独立固定轴来源求解先 PASS。
2. 初值必须满足精确结构/宽度等式及线性非负宽度等结构约束。最小二乘可能产生新生车道负宽，现增加结构多面体投影；这不是来源或动态验收。
3. 全部连接从同一组父道路口部初始化，仍每条三条解析回旋线参数，三段等长只作搜索初值；没有把旧微段写入新图，也不逐源点增加几何自由度。
4. 联合恢复允许**搜索中**暂时存在来源、端点、动力学残差；结构/宽度等硬界保持。只有全部原约束在最终状态满足既有容差，才能返回候选并冻结写出。0.35m 来源预算及最终门槛未放宽，LP 顶点不能替代失败的平顺 QP。
5. 一处失败则整路口回退，不输出已解/未解混合地图。失败报告保留最坏源 ID、原点/原段和见证；不把局部停滞或数值子问题失败写成全局无解。

仍有限制：单 Line 参考坐标图、长三次边界、固定 laneSection 事件站位；附属对象/信号/高程尚未重投影的道路拒绝。不是任意曲线参考轴、自由事件站位或全路网全局最优器。

### 4.3 OpenDRIVE 的宽度度量也要分清

OpenDRIVE 的 t 方向垂直参考线，width 沿 t 展开；它不是任意情况下都等于车道自身切线的法向净宽。例：物理等宽3.5m的平行车道与固定参考轴夹45°时，t截宽为3.5√2。该坐标变换反例已加入测试。依据：[ASAM 1.8.1 §8.3](https://publications.pages.asam.net/standards/ASAM_OpenDRIVE/ASAM_OpenDRIVE_Specification/v1.8.1/specification/08_coordinate_systems/08_03_reference_line_coordinate_system.html)、[§11.6](https://publications.pages.asam.net/standards/ASAM_OpenDRIVE/ASAM_OpenDRIVE_Specification/v1.8.1/specification/11_lanes/11_06_lane_geometry.html)（本轮已在线核对；不据此宣称改变本项目1.5消费范围）。

因此 v1.57 的 `MAP-explicit-width` 实际验证的是**暂定的“原点支持内固定t宽”转换合同**，不是坐标不变的物理宽度真值审计。
