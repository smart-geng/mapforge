## v1.74 方法修正与实施边界

1. **共同状态已扩展**：209父路独立变量＋全部16关联转向变量。首批模型509维，不再把road30冻结，也不从不同父状态挑选单条PASS。初始化模型变化可能改变转向变量数，必须按运行文件实际记录。
2. **先守住完整父路来源域**：采用有界Gauss–Newton QP限制全部原件线性不等式，每一步回溯检查非线性几何。正尺度变换只改善数值条件，不改变原容差；数值零行只有在整个允许步长盒内幅度≤1e-12才从QP矩阵省略，原行在接受前全部重算。Clarabel只负责凸QP子问题，不意味着非凸地图问题全局最优。[官方QP接口](https://clarabel.org/stable/python/getting_started_py/)
3. **有效几何域也必须逐步保持**：首个硬来源试验虽降残差且父路不越原件门槛，104偏移图仍接近奇异并产生巨大曲率。新增初值/每个接受步正宽与`1−κt`下界0.1检查，使用现有多项式极值计算，不是稀疏取几个点。正宽、来源误差、G2、曲率形状是不同条件，任何一个都不能代替其他项。
4. **固定长模型依据允许变化而非初值**：父路口部初始`t'=0`不等于优化中斜率不可变。用父路零空间后的端口线性映射判断斜率能否变化，为需要的端口预先选定端帽模型。解析反例证明旧分支会出现边缘G2精确而中心G2不连续。固定分支后再连续求解，不在数值迭代中突然增删段。仍最多5个长参考原语、每段≥6m，不增加逐原点自由度。
5. **初始化失败须可诊断**：保存初始/有界闭合/来源引导三个状态的长度、端点残差、源边界前向因子和求解器终止原因。101此次是端点残差仍约5.8e-5而非原边界折返，不能写成OpenDRIVE无解。新增小残差时的三自由坐标有界闭合校正：只选非边界、满秩坐标，其余参考参数固定；不平移曲线、不改端点目标、不降低6m。校正后仍独立检验全部来源、偏移图及最终XML，初值成功不授予地图通过。
