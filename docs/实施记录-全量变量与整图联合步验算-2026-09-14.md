# 全量变量与整图联合步验算

2026-09-14。接续全图约束接口 r5；不是地图完成报告。

## 本轮要解决的问题

此前只检查 1676 个自由变量中的 9 列，不能把其余列当零，更不能据此启动完整共同求解。来源最差见证、最近线段和中位数排序会切换，左右差分平均值也未必能正确预测联合变化。端点对上、约束函数能算和整图达到保真/驾驶要求是不同状态。

本轮新增的是完整变量检查和**同一整图状态的联合步验算接口**，没有数值拟合或 XODR 写出。`out/node4-all-source-tail-readback-v171/node4-review.xodr`仍是未通过的旧研究图，不是本轮成果。

## 实现

### 1. 所有改变的父路先更新，再更新转向

`WholeSourceConstraintSystem.trial_vector(base, vector)`先验证完整变量维度、数值及登记范围，在局部快照中更新全部改变的父路；之后一次性更新关联转向的两端、原尾段和几何。两端都改变的转向只重算一次，不能使用一个新端口加一个旧端口，也不能拼接各道路独立接受的最佳结果。

未改变的块才复用旧结果。任何源身份、布局或域错误都拒绝该步，不提交已处理的前几个父路。全图汇总与逐块值必须一致。

### 2. 保留两侧信息，不把平均差分当光滑性证明

`linearize`同时返回左右两套稀疏矩阵及明确的有效列掩码。某侧因为原域/长段下界而被拒绝时，该侧是**缺失**，不是零导数。部分列检查返回实际列数，不能补上未测列的零矩阵。

`WholeSourceStepModel`绑定准确的基准向量、原件约束身份、两侧矩阵和事前给定的各坐标允许变化范围。每个分量保留两侧差分的上下值，以构造工作预测区间。这个区间只覆盖**已测坐标方向斜率组合**，不是非线性函数的数学包络，也不是广义 Jacobian 或收敛证明。

反例测试：在 `min(a,b)` 的相等点，令 a 增加、b 减少。平均导数可能预测不变，实际最差值却下降。接口必须保留这种分歧；不能因为中位数/最差见证切换就删掉该检查。

### 3. 验算的是整个新状态，不是预测值

验算先检查变更是否使用未测列、缺失方向或超过登记范围，再计算完整实际残差。包括原本已通过的约束；返回新违例、预测漏报和实际剩余违例，并可与整图独立重算比对。

距离预算和原始不等式符号不放宽。等式仍按原混合尺度报告；本接口不把统一数值小量作为所有等式的物理验收门槛。即使工作预测显示改善，也不输出地图 PASS。完整域、动态和面域约束尚未接齐，所以始终 `export_allowed=false`。

### 4. 加速只利用已证明的代数结构

首轮 r1 检查到第 110 个自由列后主动停止，部分证据保留，未返回完整矩阵。单个普通边界系数发生微扰时，旧路径还重复计算该父路全部转向，不适合之后每个共同迭代都求导。

`SourceCoefficientStencil`对**同一基准快照、同一参考轴/切分位置/区间布局**中的系数列，保留所有原件仿射见证，直接计算 `C*x - lower + delta*C[:,j]`，对全部见证重新取最差值。包含并列及本次变化后新成为最差的见证，不仅使用原 argmin。等式使用同一 E；参考坐标正则性保留等价的有限式 `.8-k*t`。

转向是否受某个系数影响，由两端边界基函数的位置、一阶和二阶导数列是否**精确为零**决定，不按数值误差阈值裁剪依赖。任何实际端口影响仍重算该转向；全部端口的左右顺序也检查。该加速仅用于系数差分，参考轴、口部和节点位置列仍从原件完整重建。实际联合步和独立复核也走完整状态计算。

这不是恢复旧的固定父路 C/CZ 求解器；共同状态中的轴、口部和共享区间仍都是变量。没有新增几何原语、细化 width 区间、降低速度、放宽来源容差或改变九处既有角色批准。

## 方法依据与适用边界

- [SciPy NonlinearConstraint 官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.NonlinearConstraint.html)：Jacobian 的形状为约束数×变量数；稀疏结构中的零应表示真实的零依赖。此处据此明确部分列与结构零的区别，未据此宣称非光滑函数适合普通光滑算法。
- [Burke 等，Gradient Sampling Methods for Nonsmooth Optimization，2018](https://arxiv.org/abs/1804.11003)：用于认识非光滑、非凸问题与梯度采样方法的适用条件。本轮没有实现该论文完整算法，不引用其收敛结论为本项目背书；两侧工作区间仍必须靠实际整图计算检查。
- [Curtis、Overton，A Sequential Quadratic Programming Algorithm for Nonconvex, Nonsmooth Constrained Optimization，SIAM J. Optimization 22(2), 2012，DOI 10.1137/090780201](https://cs.nyu.edu/~overton/papers/pdffiles/sqpgs.pdf)：作者全文已核对。其 SQP 与梯度采样结合、按约束保留模型的思路可供后续共同求解器参考；第 6 页特别讨论把全部不等式合并成一个最大值的尺度问题。本项目因此不能把混合米/角度/正则性余量的单一最大值当验收指标；当前来源组最差值仍只用于精确可行性汇总。下一阶段要区分完整原件见证模型和非光滑转向模型，不能将本轮两侧坐标差分直接称为已实现 SQP-GS，亦不采用论文中数值等式处理策略来放宽物理门槛。
