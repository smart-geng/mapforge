# ORBIT 无编辑往返准入试验（2026-09-15）

## 结论

**本次测试版本和默认导出路径不适合作为 mapforge 的无损人工修形中转工具。停止在 ORBIT 上追加修复，不推广到转换主线。** 不是判定所有版本/所有配置都不可用，也不是已经完成其他编辑器选型。

用户要求收敛，已同意先验证现成编辑器，再决定最小本地 Web。此前全局约束/动态研究暂停扩展，现有失败样本及源资料保留。本轮没有人工拖动、没有修复后的合格 XODR，不将换工具试验写成地图交付。

- 隔离目录 `out/node4-orbit-evaluation-20260915/`，独立 Python 3.12.14 环境，依赖版本写在各样本 `packages.json`；未改变 mapforge `.venv`。下载的 vendor 目录只读使用。
- SHP 派生失败件：`out/node4-all-source-tail-readback-v171/node4-review.xodr`，SHA256 `e05dcb85db2c913081cfb1de29d88a918c4e2df019c79684f9553ad02d27a5b0`。
- MAP 派生失败初稿：`out/map-joint-v154-final/node4/initial/node4.xodr`，SHA256 `2206a1822f99fc57a1fff458b4ff39d6f622d1ad9e61bca83cf196374eb28055`。这是既存 node4 初稿，不是重新从 XML 完成转换。
- 不调用网络底图，不上传数据。不改 SHP/MAP 原件、九处批准、限速或既有失败图。

## 路径与边界

`OpenDriveImporter → Project.save → Project.load → OpenDriveWriter`；另保留不经重开的直接导出作为对照。使用导入文件原有 EQC 投影、零 header offset；由该投影派生显示控制点，不等于测量控制点/CRS 获批。无默认 WGS84、无拟合坐标对齐。

本轮是 **GUI 所用核心的准入测试**，并未运行 GUI 的导入后自动 realign，也没有人工修形。OpenDriveWriter 默认输出 1.8，不冒充项目 1.5 Profile；未改版本号蒙混过关。

`preserve_geometry=True` 在该实现里的语义是“每两个采样点输出一条 line”，不是保留导入的 Line/Arc/Spiral 原语。可复核下载源码 `orbit-core/src/orbit_core/export/curve_fitting.py` 的构造函数、`fit_polyline`，以及 `opendrive_writer.py` 的 `_create_road`。未对该第三方实现打补丁。其他拟合配置未测试；即便减少参考线碎段，也不能据此假定宽度/来源信息恢复。

## 实际结果

### SHP 派生输入

- 道路 31→31；junction 1→1；24 个连接及 laneLink 元组保持一致。
- 参考原语 **94→2193，全变为 line**；原件最短 6m，往返后最短 0.018m、中位 0.5041m；小于 2m 的原语 0→2139。
- width 814→492；laneOffset 359→96；lane speed 438→409；userData 611→2。数量不是唯一判断依据，同时按相同 road/lane/s 核对实际边缘及速度状态。
- 最严重普通道路见证：road12、lane3、s≈173.2528m，esmini 独立读取宽度从约 **3.623m 变为 430.040m**，相应边缘相差约 **284.038m**。不是输入到真实 SHP 的误差，而是输入 XODR 与无编辑往返 XODR 的差异。
- 导出后 26 个 laneSection 起点位于 road.length 之外，源件为 0；esmini 记录了截断。
- 直接导出与保存重开后导出，排除 header.date 后仍不完全相同；本轮不展开第三方内部修复。

### MAP 派生输入

- 道路 22→22；junction 1→1；16 个连接及 laneLink 元组保持一致。
- 参考原语 **54→1366，全变为 line**；原件最短约 8.1716m，往返后最短 0.0104m、中位 0.5069m；小于 2m 的原语 0→1328。
- width 623→482；laneOffset 217→58；lane speed 数量 301→301，本次采样未发现速度状态差异；userData 783→2。
- road10、lane4、s≈352.491571m，esmini 读取宽度约 **3.732m→76.224m**，边缘相差约 **217.419m**。
- 导出后 13 个 laneSection 起点位于 road.length 之外，源件为 0；esmini 记录了截断。
- 排除 header.date 后，本样本直接导出与重开导出一致；一致地保存错误几何不算成功。

### 共同问题

- 导出时未提供 reference/export warning，仍出现上述损失；不能以 writer 返回 true 放行。
- 输入的扩展来源记录未保留；输出额外写入 ODbL license userData。本项目没有授权将这些源地图重新标为该许可证，因此输出仅存作拒绝证据，不能直接分发为交付包。这是输出标签核查，不是对许可证法律适用的认定。
- esmini 加载成功只证明能解析；本次选点读回确认了巨大变形，也记录了 EQC 部分属性不支持和辅助铺面路缺链警告。没有自动驾驶控制器测试。

## 接下来收敛什么

1. **停止 ORBIT 适配，不开始修复其宽度/站位/保存逻辑。** 现成捷径的这一候选已经得到可复现否决证据。
2. 本机常见安装路径未发现 RoadRunner；这不是全盘安装/许可证证明。不采购、不擅自上传地图给外部平台。
3. 没有可用商业编辑器时，后续自研仅限本地修形纵切：原始数据与最终 XML 叠合，选择一条完整道路/共享口部，少量手柄修改长曲线/宽度，关联对象同一次重建，保存重开、导出再读回。第一项必须证明实际文件变化及关联关系守恒，而不是只画 UI 或改浏览器中的线。
4. 第一个真实编辑动作通过前，不开发账号/任务平台/批量控制台，不恢复无界全局数值研究。人眼编辑不能消除原件矛盾：来源修订留独立决定，九处批准不扩权；源限速与驾驶工况继续分开。
5. 原有 SHP/MAP 全图、CRS 与动态等未完成状态不变。当前没有新合格地图；本轮不commit。
