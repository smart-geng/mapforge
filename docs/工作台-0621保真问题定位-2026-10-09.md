# 0621 保真问题定位与来源核对（2026-10-09）

本轮交付的是工程师可用的只读定位工具与失败归因。没有接纳新的几何修形，0621 整图仍为 **T1 FAIL、T2 FAIL、G8 UNAVAILABLE、交付 BLOCKED**；WB-11 和正式发布条件继续开放。

## 页面现在能做什么

打开 0621 工程，进入“来源重建”，生成实际候选后，在“来源保真定位”查看全部 18 条可比车道。列表按原 G8 的来源→候选 P95 降序排列；2 条停止线不可测另列。点击一条，只叠加该条来源比较线和实际候选线，并缩放至两条线的范围。主来源层、记录号、part 与补充 MERGE 引用同时保留，索引注明从 0 开始。

显示的是原 G8 的完整比较区间，不是精确超限点，也不覆盖原 G8 的 139 个排除 occurrence。单车道 P95 不被另判成整图 PASS/FAIL。坐标采用来源清单与实际 XML 一致的局部米制框架，不使用原始快照的经纬度直接叠图，不声称绝对 CRS 已核验。

服务器读取本工程、本次任务绑定的实际候选和报告，以原评估器回读核对整个 G8 报告，再提取相同正宽域与支持区间。缺失、重复、错配、报告缺项或伪零均拒绝显示；缺定位数据不会变成“没有问题”。页面清除、重开、切换工程和失效会清除旧选中线，定位本身不写草稿。原铺面诊断、交付门禁和报告字节不变。

实现入口：`mapforge/workbench/fidelity_inspection.py`、`surface_editing.py` 和 `static/surface-editing.js`。真实页面与产物证明见 [本轮报告](../out/workbench/fidelity-inspection-ui-20261009/report.json)，逐项独立核对见 [定位审查](../out/workbench/stopline-audit-20261009/fidelity-inspection-final.json)及[原始来源引用审查](../out/workbench/stopline-audit-20261009/fidelity-source-refs-final.json)。
