# 局部形状检查与固定样条可行性（2026-10-09）

本轮新增一个可重放的只读局部检查器，用于拦截“整图分数改善、被修车道却新增摆动”的候选。它尚未接入客户编辑入口，不改变默认管道、评分策略或正式交付状态。0621 当前页面候选仍为 T1/T2 FAIL、G8 UNAVAILABLE、交付 BLOCKED。

## 检查对象与合同

入口为 `scripts/workbench_check_local_shape.py`，分析器为 `mapforge/workbench/local_shape_math.py`，比较器为 `mapforge/workbench/local_shape.py`。输入是实际写出的前后两份 XML 和事先声明的比较合同；不调用优化器、不生成地图。

合同绑定基线 SHA256、道路身份、唯一 laneSection 内的固定区间、固定比较分区，以及允许变化的宽度记录/横向偏移。候选自己的分段只会增加计算断点，不会改变比较分区。检查覆盖该断面所有车道的内缘、中心、外缘及 lane 0，包含分隔带。来源 ID、原限速、参考线、其他 XML 结构和域外多项式须保持；含未知元数据的可编辑多项式记录直接拒绝，避免掩盖来源或扩展信息的变化。

同一分区内分别比较每条轨迹的最大绝对曲率和沿该轨迹弧长的曲率变化率；全域检查曲率符号序列不能新增换向或方向，端口的局部/世界 C2 状态须保持，原新断点两侧的位置、方向、曲率及固定参考框架中的 t/t′/t″ 跳变不得增加。局部坐标检查避免大世界坐标的舍入吞掉实际位置跳变。整图最大值不能替代这些逐对象检查。

当前合同不比较断点曲率变化率的跳变量，不保证 C3。独立复核发现：降低原 bump 后再叠加小 C2 bump，可以降低分区曲率/曲率率峰值，同时增加断点 rate 跳变。因此“未发现本合同内的退步”不等于全面平顺；后续编辑表示的准入若需约束这一项，必须明示新合同并单独验收，不能把当前检查结果当作已检查。

支持平面 line/arc/spiral 与正宽 width 表示；不支持跨 laneSection、border、非零高程、横坡或车道高度。XML 仅接受 UTF-8，无 DTD 或实体。不能完整分析的输入返回 UNAVAILABLE；不会把数值异常、缺项或几何未变化记为正例。

分析以读取并平移后的 binary64 参数为模型，在该模型上使用有理多项式代数、导数根隔离和精确重因子检查，计算整段极值及单侧接点。相邻浮点断点保留，用有理数中点选段，不按距离合并。极值给出区间包围；无法达到所需数值精度时停止分析。这不是原始 XML 十进制、原件测量或三维几何的形式证书。

`1e-10` 的曲率/曲率率比较带和 `1e-9` 的端口/接点比较带只处理浮点误差，不能当作新的质量阈值或可利用的退步预算。直线没有额外弯曲余量；该保守合同可能拒绝所有非零修正。它不是通用修形准入标准。

| 状态 | 含义 | 退出码 |
|---|---|---:|
| NO_REGRESSION_FOUND | 在已声明范围和受支持模型中未发现局部形状退步 | 0 |
| REGRESSION | 找到明确局部退步 | 1 |
| UNAVAILABLE | 输入、范围、数值分析或证据发布不能完整完成 | 2 |

三个状态均保留 `formal_delivery=false`、`editing_capability_granted=false`、`source_fidelity_evaluated=false`。来源保真、整图门禁、消费者与产品验收仍须独立完成。用户自行编写的比较合同不授予来源编辑权限。

## 固定四跨度表示为何停止

独立推导位于 `out/workbench/local-shape-guard-20261009/feasibility/`。此处把 XML 十进制字符串直接读作有理数，数学模型与上述 binary64 分析器明确区分。结论仅适用于既定同一参考段、四个 cubic 跨度、内部 C2、两端 q/q′/q″=0，以及 `laneOffset += q, median width -= q` 的固定表达。

右 −2 中心的原曲率率为正且全域递减，右 −1 为正且全域递增；由整段 Bernstein 同号验证。因此严格不退步的两个必要端点条件分别是 `q‴(a+)≤0` 与 `q‴(b−)≤0`。端点曲率率增量的精确形式为 `A/D² × q‴`，其中 `A=1−κ_ref t>0`、`D=A²+t′²>0`。

16 个三次系数受到 15 个独立等式约束，仅剩一维。该维的两端三阶导数互为负比例：`q‴(b−)=−1.2199708417664703…q‴(a+)`。两个必要条件只能同时为零，增加这一条件后矩阵满秩，故整个修正 q 只能为零。无需扫描幅度，也不依赖 q 非负的假设。

这个结论阻止继续调同一个 bump 的幅度，**不证明更一般表示或整个路口无解**。数值误差带也不能当作非零有效改善。推导另列出的简化小坡度量级仅是观察，不是一般非线性改善上界。
