# 0621 工程迁移与离线重算

2026-10-09，接续 WB-10 和[0621 页面流程](工作台-0621保真问题定位-2026-10-09.md)。本次处理已保存工程的换目录问题，默认转换算法、原件、评分阈值与正式交付条件均不变。

## 迁移合同

旧报告包含生成时的绝对路径及代码、消费者、原料字节绑定。直接复制目录，或将报告里的路径批量替换，都不能证明旧检查在新环境仍有效。

新增 `mapforge/workbench/project_relocation.py`：将完整工程复制到全新的 workspace，核对来源字节和来源语义，仅允许 SourceSnapshot 顶层 locator 改变。未知字段中的路径值不做递归替换。草稿、撤销重做时间线、旧候选、旧检查和已有证据保留；原始当前快照另存历史。新当前快照增加版本和草稿 epoch、清除能力登记，因此旧候选和旧检查明确过期，必须重新登记、生成、检查和保存。

任务回执与请求索引严格一一核对。本工程已终止任务仅保存到 `relocation-history/<迁移ID>/jobs/`；不恢复为新会话可执行任务。活动任务、坏历史、来源漂移、Windows junction、目标冲突均拒绝；失败不发布可打开的目标工程，也不覆盖已有 workspace。当前每个工程文件仍限 128 MiB、目录总量 2 GiB；原始 SHP 清单可在 2 GiB 总量内按块哈希，不把大 DBF 作为 JSON 整体读取。

内部迁移入口如下，目标 workspace 必须不存在，原工程保留：

```powershell
.venv\Scripts\python.exe scripts\workbench_relocate_project.py `
  --project "<旧workspace>\<32位工程ID>" `
  --workspace "<全新的workspace>" `
  --source "<新位置的完整SHP原料目录>" `
  --profile "<新位置的原Profile文件>"
```

这是供工程部署使用的命令入口，尚无客户页面迁移向导。0621 当前固定编译适配器要求原料放在应用根目录的 `shp_0222-0326/` 下，Profile 放在 `profiles/shp/ibd-smarteditor-v1.yaml`；迁移接口能核验其他位置，不代表该固定编译器已支持任意布局。

## 中文路径消费者

新增显式辅助适配 `workbench_auxiliary_portable.py`，将自包含 XML 原字节传给 `RM_InitWithString`，复用既有辅助面采样、读回计算和阈值。父进程独立核对完整采样计划、行身份、宽度与位置计数、误差和零宽端点汇总；缺项或超时不能报告 PASS。

0621 的显式来源重建探针接入这个辅助适配，整图打分接入已有 `consumer_metrics.evaluate`。后者保留原评分器的其他指标，完整字节绑定消费者检查完成后采用新的两个 esmini 消费指标；检查无效或未完成时，两项明确置为 False/None，不退回旧 PASS。原默认评分板及旧辅助检查器未修改。

真实 DLL 验证中，ASCII 与中文路径下的同一份 0621 辅助面均完成 621 次宽度、1863 次位置读回，全部行、计划及误差汇总一致。另有包含零宽端点的小图验证。协议反例和受控超时测试不当作真实消费者能力证明。

## 发布边界

本机重建运行时、服务对象调用与真实浏览器操作分别记录。同机中文目录重放不等于干净 Windows 安装，也不等于物理断网：使用离线、禁下载参数，仍使用宿主 MSVC 运行库。源码/数据/esmini/XSD 的对外发行授权与完整安装包还需落实。

迁移不会修复 0621 的保真、G8 停止线缺项和 G11 问题。独立地图工程师、第二同类正例、绝对 CRS、正式用途策略、指定客户消费端和干净机器验收仍是开放事项。正式交付保持 BLOCKED。
