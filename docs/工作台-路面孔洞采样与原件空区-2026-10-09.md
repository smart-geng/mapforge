# 路面孔洞：采样修正与原件空区单列（2026-10-09）

## 用户决定

2026-10-09，用户决定：与原件空区重合的路面孔洞单列，不计入失败。两项细节由用户选定：

| 项目 | 决定 |
|---|---|
| 原件空区依据 | 只认源路面重建证据中绑定的原件空洞，即 `surface-evidence.json` 的 `source_support.original_holes`（WKB、SHA256、面积） |
| 采样 | 一并修正：铺面轮廓在每个记录断点都取样，消除弦近似造成的伪孔 |

## 背景

0621 研究候选的 T1 中，`paving_holes_gt1cm2 = 2`，这两个孔洞性质不同（工作台路面诊断已分开显示）：

- **9.7409739021 m²**：源路面重建按原件保留的空区。它与证据 `original_holes` 重合，对称差约为该空洞面积的 3.3e-9。
- **0.0223187461 m²**：采样伪孔。`smoothness.surface_continuity` 按 0.1 m 网格加 laneSection 起点取铺面外轮廓，网格点之间用弦连接。若 width、laneOffset 或 planView 记录起点不在网格上，弦会切掉宽度转折，两条铺面的共享边之间就留下细缝。这块面积被写出的 XML 路面完全覆盖。

在每个记录起点也取样之后，0621 的铺面并集面积为 666.6663 m²，与按 XML 精确计算的路面相等，只剩 9.741 m² 的真实空区；取样步长 0.1 m 和 0.025 m 的结果相同。

决定前还核对过 IBD 的路口面、ROAD_SURFACE 图层和车道边界并集，三者都不能单独界定“原件空区”。因此用户选定：只认重建时已绑定哈希的原件空洞。

## 实现

- **新模块 `mapforge/validate/paving_holes.py`**
  - `road_outline`：做法同 `road_surface_polygon`，但取样网格加入每个 planView geometry、laneOffset 记录起点，以及 laneSection 加 width（或 border）sOffset。
  - `paving_holes`：取铺面轮廓并集中面积大于 0.01 m² 的孔洞。截面不变：历史名 `gt1cm2`，实际为 100 cm²。
  - `source_holes`：核对 WKB 的 SHA256，并要求 `area_m2` 与几何面积一致（相对 1e-9）；WKB 无法解析也记为 `invalid`，否则记为 `invalid`，不绑定任何空洞。
  - `audit`：输出六项指标：
    - `paving_holes_resampled`
    - `paving_holes_source_void`
    - `paving_holes_counted`
    - `paving_hole_counted_area_max_m2`
    - `paving_source_void_area_m2`
    - `paving_source_void_evidence`（`none` / `bound` / `invalid`）
- **重合判定为双向**：孔洞须与原件空洞相交，且对称差不超过该原件空洞面积的 1e-3。原件里更大或更小的空洞，都不能抵消写出的孔洞。
- **`scoreboard`**：读取 XODR 同名的 `.surface-evidence.json` 并登记新指标。默认转换管道不产出此文件，所以评分板和泛化集的孔洞全部计数。
- **策略**：`static-acceptance-v1.draft.yaml` 由 0.8-draft 升为 0.9-draft。T1 的 `paving_holes_gt1cm2 ≤ 0` 改为 `paving_holes_counted ≤ 0`，阈值和截面都不变，原指标继续报告。
- **工作台单候选检查 `surface_validation`**
  - 候选运行必须绑定 `surface-evidence.json`：源轨迹、源单元两种运行器本就把它列为必需产物。
  - 检查包把它复制为 `candidate.surface-evidence.json` 供评分读取，复核时逐字节比对，检查包产物集合因此多一项。
  - 编译运行目录里的 `scoreboard.json` 不读这份证据（文件名不同），孔洞仍全部计数。它本来就不作为检查结果。
- **未改 `smoothness.road_surface_polygon` / `surface_continuity`**：它们受证据绑定，工作台路面诊断也在用。
- **测试**
  - 新增 `tests/test_paving_holes.py`，覆盖：
    - 共享边上的宽度折点在旧网格上形成伪孔，按断点取样后消失；
    - 方框孔洞只在与绑定空洞重合时才不计；
    - 更大、更小或位置不符的空洞不能抵消；
    - 哈希或面积不符时，证据无效；
    - 0.9 策略口径；
    - 0621 真实候选（资料恢复后才运行）。
  - `tests/test_workbench_surface_validation.py` 的合成候选加入 `surface-evidence.json`，并检查三点：评分读到该证据、缺证据拒绝、证据被改则拒绝。
  - `tests/test_tight_turn_conflict.py` 的策略版本断言改为“不早于 0.8”。
