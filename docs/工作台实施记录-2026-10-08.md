- `mapforge/workbench/sources.py`：无 XODR 读取 SHP，按源快照、图层、记录、part 建身份；业务 ID 重复不合并。原字段、Z/M、多部件和未知内容引用保留。
- `contracts.py` / `store.py`：新工程独立于旧研究 Project。已确认待办原子保存、重开、撤销重做；版本冲突和重复命令受控，损坏快照先只读打开上一完整版本，恢复须保留损坏件。
- `app.py` / `static/`：真实源画布、路口导入、图层开关、搜索、对象选择和定位、原字段、待办和源问题。正式交付入口禁用，页面明确标记开发版。

- `crs_audit.py`：原件声明、显式 PROJ 正反算、七份原始 MAP 相对叠合、独立材料缺口可重放审核；生产 CRS 未通过。见[坐标系审核](坐标系审核-2026-10-08.md)。
- `measurements.py` / `static/inspection.js`：按单个原始 part 或画布两点只读量距；页面显示声明口径及单位。重叠线条可按图层、原记录和 part 选择。量距不进入草稿，不授予坐标核验或编辑权限。
- `exports.py`：当前候选、已保存完整检查及成功任务回执共同绑定研究 ZIP；原子发布后回读校验，工程或产物变化时拒绝。正式交付权限不变。
