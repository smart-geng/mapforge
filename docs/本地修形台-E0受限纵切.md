## 明确支持与限制

- 当前固定登记 node4 **SHP** 源及 v1.71 失败 XODR 基线；不是任意地图导入器，MAP XML 的中心采样/镜像来源尚未接入此编辑页。
- 7 个手柄：`10:2`、`13:1`、`11:-1`、`12:-3/-2/-1/2`。只有相邻两车道全段存在、有明确双向 laneLink、共用既有宽度区间且参考为单个 Line/Arc 时才开放。
- 一个手柄对应一条共享物理分界线，两个相邻宽度相反变化，边界/车道中心/标线的 OpenDRIVE 宽度语义一起变化。参考轴、其他边界及两端接缝保持不变；连接路无需改动是因为端口锁死，不是假装完成口部联动。
- **外缘、路口口部、曲率轴、拓扑和铺面仍锁定**。当前不能靠本页消除西/南外缘缺陷或修好整个路口。没有宣传“一拖必好”。
- 每个意图使用四个长三次变化区间；结点落在原已有 width/section 边界上。输入点密度、绘制采样密度不决定控制量数量，**新增 geometry/width/laneSection/laneOffset 均为 0**。旧图已有密集横断面未因此消失；不能称已完成全部非碎段门禁。
- 修改宽度的非负性与常曲率偏移坐标 `1-k*t` 使用三次多项式极值检查。C2 增量在支持区间外为零，端点位置/切向/曲率锁定。原图旧缺陷、源保真、动力学、面域、绝对 CRS 另列，不给 PASS。

几何基函数使用 SciPy 的 [BSpline.basis_element](https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.BSpline.basis_element.html)，写出时精确换算回既有区间的三次幂基系数，不采样成短 line。服务采用 [FastAPI 静态资源机制](https://fastapi.tiangolo.com/tutorial/static-files/)的本地部署原则，本实现仅对白名单三个静态文件提供 FileResponse。
